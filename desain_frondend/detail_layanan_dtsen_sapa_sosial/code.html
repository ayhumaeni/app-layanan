Tentang Surat DTSEN

Surat Keterangan DTSEN adalah surat resmi yang menyatakan status desil ekonomi atau kepesertaan keluarga Anda dalam database kesejahteraan sosial nasional dan daerah untuk mengakses program afirmasi pemerintah secara adil dan transparan.

route Alur Pelayanan Digital (4 Langkah Mudah)

1

Pengajuan Online (5 Menit)

Isi data identitas diri dan unggah berkas KTP serta Kartu Keluarga lewat formulir digital.

2

Verifikasi Petugas (1 Hari Kerja)

Operator Dinsos memvalidasi kesesuaian berkas dengan basis data DTKS/DTSEN Kabupaten Blitar.

3

Penerbitan Surat Ber-QR Code

Dokumen resmi disahkan dengan Tanda Tangan Elektronik (TTE) tersertifikasi BSrE BSSN.

4

Unduh Mandiri / Cetak

Surat langsung diunduh dalam format PDF asli, atau diteruskan otomatis ke nomor WhatsApp pemohon.

help Tanya Jawab (FAQ DTSEN)

Berbeda. SKTM diterbitkan oleh Pemerintah Desa/Kelurahan, sedangkan Surat Keterangan DTSEN diterbitkan langsung oleh Dinas Sosial Kabupaten Blitar berdasarkan pencocokan data desil kemiskinan nasional (DTKS Kementerian Sosial RI).
Surat Keterangan DTSEN berlaku selama 3 (tiga) bulan sejak tanggal disahkan secara elektronik. Jika masa berlaku habis dan masih diperlukan, Anda dapat mengajukan perpanjangan kembali.
Bila NIK Anda belum terdata dalam basis data DTKS pusat, sistem akan memberikan notifikasi rekomendasi pendaftaran usulan baru melalui Musyawarah Desa/Kelurahan (Musdes) atau layanan Puskesos terdekat.
